About

I'm a cybersecurity enthusiast and Junior Penetration Tester with hands-on experience in web application security, CTF challenges, and offensive security labs. My focus is understanding how applications break — and documenting it clearly enough to be fixed.

I've worked extensively across the OWASP Top 10, including XSS, SQL Injection, IDOR, SSRF, LFI and access control issues, using Burp Suite, Nmap, Metasploit, ffuf and sqlmap.
